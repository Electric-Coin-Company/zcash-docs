zcashd reached end of support on 18 July 2026

Released zcashd binaries halt at a hard-coded deprecation height. Version 6.20.0 stopped at block 3,417,100 and refuses to restart, and zcashd does not support NU6.3 (Ironwood), which has since activated on mainnet.

Run Zebra instead. To migrate a zcashd wallet, see Zallet. The migration path is described in the official zcashd deprecation notice and on the end-of-life page.

Much of this site predates that transition.
